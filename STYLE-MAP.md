## Maintenance rule

When changing an existing component:

1. Find its class in the **Active HTML component map**.
2. Open every listed CSS definition, not merely the first one.
3. Check whether a shared safeguard or later override also affects it.
4. Check the JavaScript section if behaviour is involved.
5. Prefer the semantic guidance in `STYLE-INDEX.md` when choosing a component for new content.
6. Regenerate this map after substantial component or stylesheet changes.

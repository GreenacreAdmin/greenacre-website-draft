# Greenacre website instructions

## Adding or replacing photographs

- Retain the target website layout. Preserve the existing image frame's aspect ratio, dimensions, responsive behaviour, spacing and surrounding design unless the user explicitly requests a layout change.
- Fit the photograph to that frame through appropriate cropping and positioning; do not reshape the layout to match the source photograph's proportions.
- Check the existing target frame before choosing a crop. Preserve important faces and the main interaction, and verify the result on desktop and mobile.
- Follow any user-specified crop direction. For the current Work With Us photograph, retain the original 3:2 frame and crop from the top (bottom-align the image).
- Use appropriately sized, compressed responsive image assets for efficient loading.

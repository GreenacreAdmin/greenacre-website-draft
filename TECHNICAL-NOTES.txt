Greenacre website technical structure

The website remains plain static HTML for GitHub Pages, with no build step required to serve it.

Shared styling is in assets/site.css (one file, sections named by purpose). The shared inner-page layout is in assets/page-base.css, and each page's own styles are in assets/pages/<page>.css. Pages contain no inline <style> blocks.

The header and footer are kept in partials/ and copied into every page by scripts/build-shared.py, which also writes the page-banner trail from the menu. scripts/check-site.py verifies that pages are in step.

All files are referenced relatively, so the same files work under the GitHub Pages project path and later under the custom domain.

The old /parent-information/ecas/ file remains a redirect/stub and is not treated as a full page.

See MAINTENANCE-GUIDE.md, "Site structure (October 2026)".
